# AGENTS.md

This repository's rules for coding agents live in `CLAUDE.md`. Read it first and follow it: the hard rules, commands, structure and writing style apply to every agent, whatever tool you are.

If you were asked to continue an autonomous plan, read the plan file named in the request (for example `docs/AUTONOMOUS_PLAN_3.md`) and its status file, then continue from the status file's "Next action".

## What was built

A long-only Munich class studio with20 authored features,49 events,150 interview
quotes,four intro cards and two native360×170 shop/annex scenes. The established
accent remains#B0284F (white contrast6.44:1). All three interface voices use the
existing notebook/Calendar design. The studio is registered for the fitness milestone.

- Eight-week paid fit-out,real showers/quiet works,twenty bikes bought or leased,
  and actual class preparation. The same-building adjoining mat room has its own
  construction time andEUR3,800 monthly rent;no second studio location is built.
- Spin/strength/yoga/lunch/reformer classes reserve actual shared room hours.
  Scheduled classes need one qualified paid/founder shift each,even when empty.
  Founder and named retained instructors have the stated12-class workload limit.
- Product-specific paid memberships,annual terms,off-peak restrictions,owed
  packs,intro conversion and invoiced employee plans. Public terms show real
  usable products,pack visits/expiry and optional typical weekly frequency.
- Finite paid-conversion enquiries from the founder's original following;
  actual instructor departures stop their followers and appear in the post-mortem.
- Reformer installation costsEUR36,000 and reduces the existing mat room from18
  places to8. Specialist interest is a variable niche,learnable through interviews,
  with actual paid-offer consequences. The recovery room remains a named trap.
- Fictional Turnsaldo pays actual check-ins,with visit caps,slot selection,
  leaving notice and membership migration. Corporate-labelled check-ins settle
  directly instead of creating spurious invoices to visitors' employers.
- Optional shared member/platform reservation arrivals reserve one real place
  each;actual refused member reservations affect waitlists and service reviews.
  Existing ordinary/founding/intro fallbacks and old unconfigured paths are explicit.
- Class history compacts to current service/future reservations plus54 weekly
  traffic rows and lifetime totals.21 full results/public traces match the original
  representation. An inconclusive additional capacity cache was discarded.
